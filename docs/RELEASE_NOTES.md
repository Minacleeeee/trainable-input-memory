# v1.0.0 - Evidence release

English empirical report, six saved-result exports, complete selected-study response records, split archives and 20 association introduction baselines, 76 historical Python files, and a standard-library verification tool.

Separate model asset: six checkpoint selections and the frozen maintenance adapter, with hashes. No full base weights are bundled.

The release demonstrates limited vocabulary transfer for a trained opaque command and retention under isolated input additions. It does not establish superiority to textual skills or long-project context compression. No new neural inference/training was performed for this publication. See the paper and critical review for failures and limitations.
