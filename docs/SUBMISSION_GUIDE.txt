B. SUBMIT TO ARXIV
1. Sign in and choose START NEW SUBMISSION. Complete author agreement and account checks with your true identity. Suggested field: cs.CL (Computation and Language); use the category that accurately describes the paper, rather than selecting a category just to avoid endorsement.
2. If endorsement is required, follow arXiv's endorsement process. Successful registration does not guarantee submission eligibility or acceptance. Do not invent an affiliation, endorser, journal reference, or DOI.
3. Select CC BY 4.0 to match the supplied manuscript license. Read the actual agreement before confirming it.
4. Upload arxiv_source.zip. Select main.tex as the top-level file and PDFLaTeX as processor if asked. Standard TeX Live packages are used; no shell escape or custom fonts are needed.
5. Wait for processing. Open arXiv's generated PDF and check all 8 pages, especially both tables, six response examples, author name, references, and AI disclosure. Local compilation passed; the server-generated PDF still requires inspection.
6. Copy the fields from ARXIV_METADATA.txt. Add the actual GitHub URL to Comments if space permits, for example: "8 pages; code, evidence and parameter assets: [actual URL]". Replace that example with the real URL, not literal square-bracket text.
7. Review the submission preview and author list. The sole paper author is Shenghe Li. OpenAI Codex and ByteDance Seed2.1 appear only in the AI assistance section.
8. Complete the final Submit step yourself. Save the submission identifier and confirmation. Moderation and scheduling happen afterward; submission confirmation is not publication or acceptance.
9. When arXiv assigns a public identifier, add its actual URL to the GitHub README and release description. Do not fabricate an identifier in advance.

WHAT TEX SOURCES MEAN
arXiv needs the files required to build the paper: .tex and any included figures, bibliography output/source, custom style files, etc. This paper keeps tables, examples, and the bibliography inside main.tex, so one .tex file is sufficient. arxiv_source.zip deliberately excludes the generated PDF, compilation logs, experimental Python, datasets and model parameters. Research code/data can be published separately on GitHub; they are not mandatory TeX compilation dependencies. Optional arXiv ancillary files are a different mechanism.

WHAT HAS AND HAS NOT BEEN VERIFIED
Primary saved-response statistics, split checks, export/source hashes, parameter asset hashes, English PDF layout, and source-only compilation are checked. The release contains historical training source snapshots; it is not a tested clean-machine neural training/inference package. No new model calls were made for publication, and no claim of independent human peer review is made. Read docs/CRITICAL_REVIEW.md for the scientific boundaries.
